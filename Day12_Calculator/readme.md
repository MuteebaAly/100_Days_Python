# My Python Calculator

## About My Project
I built this simple command-line calculator using Python to practice my coding logic. It features a cool retro calculator design right at the start and lets you perform basic math operations smoothly without any annoying crashes.

## How It Works
The program runs by taking step-by-step inputs directly from you. First, it asks you to enter your first number, then it displays the math symbols so you can choose an operation, and finally, it asks for the next number to give you the instant result. I also added smart error handling, so if you accidentally try to divide a number by zero, the program won't crash—it will just gently warn you and let you try again.

## Keeping the Calculation Going
After showing the answer, the program asks you what you want to do next. If you type `y`, it automatically saves your last answer so you can keep applying more operations to it. If you type `n`, it resets everything so you can start a brand new calculation from scratch. If you type `q`, it cleanly closes the program.
