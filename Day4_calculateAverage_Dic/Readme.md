# Student Average Marks Finder

### Project Objective
This script calculates the average marks for a specific student:
1. Asks the user for the total number of students.
2. Takes the student's name and all their marks in a single line, then saves them in a dictionary.
3. Searches for a specific student's name and prints the average of their marks.

### How it Works
* **Dictionary:** Stores the student's name as the key and their marks as a list.
* **`*line` Unpacking:** Separates the student's name from their marks during input.
* **Loops:** Used to collect data for $n$ students and to sum up the marks for the final average.
