A fun, interactive Command-Line game built with Python using classic game rules.

### What I Practiced:
- **User Input & Validation:** Handled choices (0-2) and wrong inputs.
- **Randomization:** Used `random.randint()` for unpredictable computer moves.
- **Nested Logic:** Wrote clean conditional blocks to decide the winner.


### The Main Logic (How it works)
- **Tie:** `Human_choice == computer_choice`
- **User Wins:** (Rock beats Scissor) OR (Paper beats Rock) OR (Scissor beats Paper)
- **Computer Wins:** Any other combination!

### How to Play:
Run the script, enter your name, choose a number, and see if you can beat the computer! 😎
