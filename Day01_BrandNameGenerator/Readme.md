# Brand Name Generator

A minimal and simple Python script that generates a unique brand name by combining two user inputs: the name of their city and their pet's name.

## How It Works
The script takes two inputs from the user, concatenates (adds) them together, and displays the final brand name output.

## How to Run

1. **Make sure you have Python installed.**
2. **Run the script via terminal:**
```bash
python brand_name_generator.py
